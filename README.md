# Kotlin Simple Chatty Bot 🤖

A simple console application written in Kotlin that interacts with users, guesses their age using mathematical logic, counts to any number, and tests programming knowledge. This project was completed as part of the Hyperskill (JetBrains Academy) learning platform.

## Features

- **Interactive Greeting:** Welcomes the user and asks for their name.
- **Age Prediction:** Calculates the user's age based on division remainders using modular arithmetic.
- **Number Counting:** Sequences numbers from 0 up to a user-defined limit.
- **Knowledge Quiz:** Tests basic programming concepts with built-in input validation.

## How to Run

1. Make sure you have the Kotlin compiler or an IDE installed (like IntelliJ IDEA or Android Studio).
2. Clone the repository or copy the code into your project.
3. Open `Main.kt` (or the file containing the `main` function).
4. Run the `main` function.
